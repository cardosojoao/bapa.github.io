I'm João Cardoso, a software developer with a passion for building games, engines, and the tools that bring them together.

bapa.one is where I share my work on the ZX Spectrum Next: the ideas, technical decisions, and experiments involved in creating a game for an 8-bit machine.

## What I'm building

**dot8** is my game engine for the ZX Spectrum Next, written in Z80 assembly. It brings together rendering, animation, physics, collision detection, audio, and scene management. Building it is an opportunity to explore how those systems fit within the machine's memory and processing limits.

**Tidal Quest** is the game taking shape alongside the engine. It follows Violet through a flooded world, searching for forgotten technology that could help her people. Its development connects the technical work with level design, pixel art, and storytelling.

I also build tools to support that work, including **dot8assetmanager**, a Visual Studio Code extension for processing game assets. My workflow combines Z80 assembly with C# and TypeScript tools, using Tiled, Aseprite, and CSpect along the way.

## What you'll find here

I write about engine design, memory organisation, asset pipelines, and my development environment. The articles document the decisions I make as these projects evolve, with practical details that other developers can use in their own work.

You can explore the [archives](/archives/) or find my projects on [GitHub](https://github.com/cardosojoao).
